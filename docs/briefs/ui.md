# Module part — UI (Arabic, touch-first, landscape stage)

**Owned files**: everything under `game/src/ui/` (`ui.js` root + one file per view, `styles.css`, `strings.ui.ar.js`) · `game/harness/ui.js`.
Contract: ARCHITECTURE §8 and the "Stage and touch" rules of §1; DESIGN §3, §4, §7; glue items 1–7, 14, 15. The current `ui.js` is a working baseline — replace it with the real thing. Read `systems/director.js` (search `G.ui.`) and `src/main.js` to see exactly how the kernel drives the UI.

## Character
The interface is part of the art direction: sand/ivory panels, thin dark-brown rules, and a **Sadu** weave strip (red / black / white geometric triangles and diamonds, drawn as an inline SVG pattern) as the signature border of cards, dialogue and menus. Titles in «Aref Ruqaa», everything else in «Tajawal» (fonts are already in `app/public/fonts`, `@font-face` rules exist in `styles.css`). Arabic, RTL text; controls are NOT mirrored. Arabic-Indic digits in cards and counters (`arDigits` in `core/strings.js`). Calm, dignified, legible outdoors on a phone: large type (dialogue ≥ 18 px, scaled by `settings.textScale`), strong contrast, soft shadows under text over the 3D scene, no gamey chrome. Motion is restrained (150–300 ms eases; CSS transitions are fine).

## Stage rules (critical)
Everything lives inside `#ui` in the `#stage` element, authored for LANDSCAPE only. When the phone is held with rotation lock, the kernel rotates the stage 90° — so never use `window.innerWidth/innerHeight`, `vw/vh`, `position: fixed`, or raw `clientX/clientY` deltas. Use `G.stage.w/h`, `G.stage.toLocal(clientX, clientY, out)`, `G.stage.delta(dx, dy, out)` and the CSS variables `--sw`, `--sh`, `--sa-t/-r/-b/-l`. Test both `--w 844 --h 390` and `--portrait --mobile` (rotated) — pointer coordinates must map correctly in both.

## Views to deliver
- **touch**: floating stick in the left 45 % (radius 56 px, dead zone 0.12, knob turns gold past 0.90 = run) → `G.input.setMove`; look drag everywhere else → `G.input.addLook` at the glue-6 scale; context button ⌀ 76 px bottom-right rendering `G.sys.interact.verb` every frame (label via `G.t(labelKey)`, hold ring from `progress`, dimmed when `kind` is null) → `G.input.setHeld('interact', …)`; eye button ⌀ 64 px on the thumb arc up-left of it → `setHeld('firasa', …)` (hold, or toggle per `settings.firasaToggle`); قربة icon (hold → `setHeld('drink', …)`, ring from `survival.drinkProgress`); pause top-left → `G.input.tap('pause')`. Multi-touch with per-pointer ids; a touch that starts on a hold button keeps the button down and also steers the camera after it moves 12 px (0.6×); `touch-action: none`; no scroll, zoom, selection or long-press callout; targets ≥ 48 px and ≥ 24 px + safe-area from the edges. Mouse look on desktop is already handled by the kernel (`core/input.js`): handle only `pointerType` touch/pen for stick and look, but buttons must work with the mouse too. Hide touch-only controls when `G.input.device` is not `touch` (show small key hints instead).
- **hud**: objective line top-right (tap → `objectives.poke()`), hint line under it; horizon strip top-centre (cardinal ticks + `objectives.marks` placed by bearing relative to `G.actors.cam.yaw`; icons `goal suhail jady sun camp voice`); قربة level; the steady ring drawn around the projected world target of `steady.activeRequest` (project with `G.camera`, convert to stage px; pulse red-gold while `steady.tension`); the interact world marker (a small Sadu diamond at `interact.verb.at`); star-gaze reticle from `G.sys.stars.active`; gust warning (wind streaks sweeping in from the windward screen edge on `weather:gustWarn`, impact flash on `weather:gust`); `ripple(bearingFn | null, { arrow })` (soft rings on the screen side of a sound; becomes an arrow); `glint(bearingDeg)` (a gold glint on the screen edge; also on `firasa:ping` and `wolf:telegraph`); `toast(msg | { who, name, text }, seconds)` (non-blocking speech lines, queue of 2); `prompt(key | null)` (tutorial prompt with a small animated glyph); `count(n | null)` (a big Arabic-Indic numeral pop); الفراسة vignette (from `firasa.amount`); thirst vignette + icon pulses (from `survival.thirst`, `survival:level`); `show({ eye, water, strip })` progressive visibility (persist nothing: chapters call it at every beat start). Positions that track the 3D world update every frame via transforms only (no layout thrash; write the DOM only when a value changes).
- **dialogue**: speaker name plate + text with a quick typewriter (`typing`, `finishTyping()`), a "next" glyph; `choices(prompt, [{ label, confirm? }])` → buttons (input locked 0.7 s when they appear; `confirm` options need a 0.5 s hold with a filling ring) → emits `ui:choice { index }`; `hideChoices()`.
- **cards**: `setFade(alpha)` (full-screen black layer), `show({ num, title, sub })` chapter/narration card with the Sadu strip, `hide()`, `letterbox(bool)` cinematic bars.
- **menus**: `showTitle()` — the title «هيبة الصحراء» / «الربع الخالي — ١٨٩٩م» over the live 3D scene (a soft scrim; must also look right over a plain colour), buttons ابدأ الرحلة / أكمل الرحلة (only with progress) / الفصول (chapter select: الأثر · المسير · ليلة سهيل · حق الملح · الهيبة, locked beyond `G.save.data.unlocked`) / الإعدادات (quality auto/low/medium/high, master/music/sfx volumes, look sensitivity 0.5–2×, invert Y, eye hold/toggle, text size, haptics → glue 15) → emit `ui:start { continue?, chapter? }`. `showPause(bool)` (أكمل / أعد المشهد → `G.sys.director.restartBeat()` / الإعدادات / القائمة الرئيسية → `G.sys.director.stop()`, `G.setMode('title')`, `showTitle()`). The UI owns the pause UX: on `G.input.pressed('pause')` during `play`/`dialogue`/`cine` → `G.setPaused(true)` + `showPause(true)`; resuming → `G.setPaused(false)`. `showEnding(summary)` (`summary = { flags, stats }`: a recap of the player's choices in four lines, credits «صُنعت بـ Higgsfield», buttons العب من جديد / الفصول). `hideAll()`.
- **loading**: `show(bool)`, `set(progress)` — progress line with the Sadu strip and one short line of Bedouin wisdom from `strings.ui.ar.js`.
- A «أدِر الجوال» hint while `G.stage.rotated` until the first input.
- `ui.update(dt)` runs while paused. Haptics (`navigator.vibrate`, Android only, if `settings.haptics`): short ticks on confirm, gust impact, steady stages.

## Harness `ui`
Params `view=title|hud|dialogue|choices|card|pause|settings|chapters|ending|loading|steady|gust|all`. Each sets up the state with fake data (objective, marks, a steady request with a moving target, toasts, a card…) so every view can be screenshotted; `view=touch` simulates touches through real `PointerEvent`s to prove the stick/look/buttons write the right values into `G.input` (print them). Deliver screenshots of every view in landscape 844×390 and the main ones rotated (`--portrait --mobile`).
