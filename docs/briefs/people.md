# Module part — PEOPLE: humanoid wrapper, player, camera, NPCs

**Owned files**: `game/src/actors/humanoid.js` · `game/src/actors/player.js` · `game/src/actors/camera.js` · `game/src/actors/npc.js` · `game/harness/people.js` · `game/harness/camera.js`.
Contract: ARCHITECTURE §5 `humanoid.js`, `player.js`, `camera.js`, `npc.js`; DESIGN §3–§4 (frozen numbers); glue items 6, 9, 10, 13. The current files are working baselines — rewrite or extend them, the contract decides.

## humanoid.js
- Six rigged GLBs (`dhari mani misfer moudi fuhaid jaber`), one shared 24-bone skeleton layout, in-place clips (see ARCHITECTURE §3 for the clip list per model). `G.assets.instance(id)` returns a `SkeletonUtils` clone with `userData.animations`.
- Logical clips `idle walk run sit kneel drink torch swing call steady pull talk lie aim wave`; a missing clip falls back sensibly (run → walk faster, talk → idle with a small procedural hand/head gesture, lie → sit lowered, kneel → sit, others → idle) — never throw. Missing model → a capsule stand-in with the same API.
- `locomotion(speed)`: idle ↔ walk ↔ run blended by ground speed with synchronised phase, time-scaled so feet do not slide (measure each model's stride from its walk/run clip once and cache it).
- `overlay(clip | null, { mask: 'upper', fade })`: an upper-body action (spine and above) over the locomotion — carrying the torch, swinging, calling, aiming while walking.
- `socket(name)`: `handR handL back head hips` — child Object3Ds with world-unit scale and actor-aligned axes in the bind pose, so an item authored in metres with +Y along its shaft can simply be added.
- `lookAt(target | null)`: damped additive neck/head turn (≤ 60° yaw, ≤ 30° pitch), applied after the mixer.
- `sitOn(parent | null)` (glue 9) and correct root offsets so `sit` rests on the ground/saddle, `kneel` and `lie` rest on the ground — per-model constants you measure from the clips.
- Explicit bounding sphere; LOD1 via `G.lod.add` (near 18 m; same vertex buffers, 20 % index from `G.assets.lodGeometry(id)`); blob shadow via `G.world.decals.blob(root, 0.45)`; mixers at half rate beyond 40 m; `setTint` (clone the material only when tinted), `setVisible`, `dispose` (removes LOD/blob registrations; never disposes `G.assets` resources).

## player.js (Dhari)
- On foot: camera-relative; walk `2.0 · min(1, moveMag / 0.6)` m/s; run 5.0 m/s when `moveMag > 0.9` or `run` is held and no limit forbids it; turn 540°/s; smooth acceleration; uphill slows (`terrain.slopeAt` along the heading, up to −35 %), soft sand −15 %; circle push-out against `G.world.props.colliders`, NPCs and camels; soft level boundary (`L.bounds`): past the radius the hero is turned back gently and `player:bounds` is emitted (at most once per 6 s). Never under the terrain; y = `heightAt`.
- `limit(tag, { speed?, speedMul?, run? })` → `{ remove() }`, stackable (the strictest wins; multipliers multiply). `player.onBeatEnd()` removes every limit whose tag does not start with `level:` (those survive until the level unloads).
- Steps: `player:step` per glue 10. `player.trail`: ring buffer (64) of positions every 0.5 m — followers walk it.
- `mount(camel)` → Promise: scripted (the Bedouin way): walk to her left side → `camel.pose('kneel')` unless `camel.kneeling` → `actor.sitOn(camel.saddle)` → `camel.pose('rise')` → mode `mounted`, `camel.ridden = true`, emit `player:mounted`. ≈ 3 s in total (`fastText` ≤ 0.1 s). `dismount()` is the reverse and leaves Dhari standing on her left. `player.mounted` → the camel or null.
- Mounted: stick x steers at 75°/s; stick y > 0.2 walks 2.4 m/s; > 0.9 trots 5.5 m/s (unless limited); no reverse; the player drives the camel each tick (`camel.place`, `camel.setSpeed`); slope and soft sand affect speed slightly; emits camel steps.
- `push(vx, vz)` (an impulse that decays) · `knockdown(seconds, { slide })` → Promise (he is thrown down, slides, gets up; input ignored; emits `player:knockdown`; dhari has no `lie` clip — use `kneel` plus a procedural root tilt) · `equip(item | null, { lit })`: `'torch'` and `'staff'` in the right hand, `'rifle'` slung on the back, built with `G.world.props.make(item)`; the torch gets `G.world.props.flame(item, { size: 0.35 })` and the `torch` carry overlay; `player.item` · `swing()` → Promise: auto-aims (turns) toward `G.actors.wolves.next` when it is within ± 60° of the view, emits `player:swing { x, z, yaw }` at the start, plays `swing` as an upper-body one-shot, the brand stays raised 0.5 s · `setScripted(on)` · `moveTo(x, z, { speed, stop })` → Promise · `spawn` / `teleport`.
- In modes `dialogue` / `cine` the hero does not move (the director also locks input). `onBeatEnd()` releases scripted state; `onLevelUnload()` resets.

## camera.js (`G.actors.cam`)
- Follow: distance 4.2 m on foot / 7.5 m riding (eye height 2.6 m when riding), orbit pitch −15°…+65°, FOV 55°. Look input per glue 6. Spring arm never under the terrain (keep ≥ 0.6 m above `heightAt` along the arm, and pull in rather than clip through dunes/props); smooth, no jitter on slopes. On foot: auto-align behind the hero after 1.5 s without look input (only while moving). Riding: follows the heading at 90°/s after 1.0 s without look input (one-thumb riding).
- `frame(target, { duration })` eases the view onto a target without taking control (the director uses it at beat starts). `softLock(target | null, { shoulder })`: aims at the target in 0.4 s, allows ± 20° of nudge, slides over the right shoulder (0.6 m right, 3.0 m back). `skyMode(on)`: pitch limit +85°, sensitivity 0.6×, used with `magnet` (glue 6). `shake(amplitude, duration)`. `aimError(target | dirFn)` → radians between the view axis and the target direction. `setDistance(d)`, `setFov`.
- `cine(shots)` → Promise: `[{ pos, look, dur, ease?, fov?, cut?, skippable? }]` where `pos`/`look` are points or functions returning points (moving subjects); interpolates between shots unless `cut`; `skip` fast-forwards; `fastText` ≤ 0.1 s. The camera holds the last shot until `release({ duration })` blends back to follow. `cut(pos, look)`, `snap()`.
- `lateUpdate(dt)` writes `G.camera`; zero allocations.

## npc.js
- `npcs.spawn(id, modelId, { x, z, yaw, tint, scale, clip })` (idempotent per id) → npc with `goTo` (promise; simple steering around colliders; walks on the terrain; arrives facing the travel direction), `follow(target, { dist, speed })`, `followTrail(player, { behind })` (walks the player's recorded path — the child in the storm), `stop`, `lookAtPlayer(on)`, `ride(camel)` / `unride()` (glue 9; instantaneous — riders mount off-screen), `speak(on)` (talk gesture while a dialogue line is theirs), `place`, `play`, `playOnce`. NPCs keep a 0.45 m personal circle and never push the player around.
- `npcs.crowd(modelId, [{ x, z, yaw, tint?, clip, t }])` → `{ setVisible(b), remove() }`: extras with zero skinned meshes — sample the clip at time `t`, bake the skinned pose on the CPU into static geometry (LOD1 index is fine) and draw the poses as plain meshes sharing the model's material (tint per instance via a cloned material or vertex colour). Used for the tribe at the fire and the riflemen's circle.
- `get`, `remove`, `clear`, `onLevelUnload`.
