Client setup on your development machine:
  cd game
  npm ci
  npm test
  npm run build

Higgsfield platform build (Bun and app dependencies required):
  cd app
  bun install --frozen-lockfile
  bun run build

Browser QA needs an already installed Playwright with Chromium. Our tests ran
Chromium 153 with SwiftShader software rendering, not Safari or physical phones.
Use a development bundle to expose the test API:
  cd game
  node tools/build.mjs --dev --harness
  node tools/v2-review.cjs <absolute-repository-path> <evidence-output> scenes
  node tools/v2-review.cjs <absolute-repository-path> <evidence-output> walkthrough
  node tools/v2-review.cjs <absolute-repository-path> <evidence-output> perf
  node tools/v2-quality-runtime.cjs <absolute-repository-path> <evidence-output>

Rebuild production before deployment:
  node tools/build.mjs
Production removes development APIs. Higgsfield deploys the pushed app/public.
